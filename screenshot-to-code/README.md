# 🖼️ Screenshot to Code

Upload a UI screenshot, pick a template style, and generate clean HTML/CSS code.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ Features

- **Upload screenshots** via drag & drop
- **5 template types**: Dashboard, Landing Page, Login Form, Card Layout, Pricing Page
- **Color customization** with presets and custom picker
- **Live preview** in iframe
- **Copy code** to clipboard
- **Responsive** generated code
- **No API key needed** — template-based generation

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📖 Usage

1. Upload a screenshot of a UI you want to recreate
2. Select a template type that matches the layout
3. Choose a color scheme
4. Optionally describe the UI for better context
5. Click "Generate Code"
6. Copy the HTML/CSS or preview it live

## 🎨 Template Types

| Template | Description |
|----------|-------------|
| 📊 Dashboard | Admin panel with sidebar, stats, charts |
| 🚀 Landing Page | Hero section, features, CTA |
| 🔐 Login Form | Split-layout login/signup form |
| 🃏 Card Layout | Product/content card grid |
| 💰 Pricing Page | SaaS pricing table with tiers |

## 🛠️ Tech Stack

- React 18
- Vite
- Template-based code generation
- iframe preview
