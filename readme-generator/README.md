# 📝 README Generator

Create beautiful GitHub READMEs with a form-based editor and live preview.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.0-green.svg)

## ✨ Features

- **Form-based editor** for all README sections
- **Live markdown preview** as you type
- **Pre-built templates** for Node.js, Python, React, Docker projects
- **Badge generator** (license, version, build status, etc.)
- **Copy to clipboard** and **download as .md**
- **Dynamic lists** for features, tech stack, prerequisites, etc.
- **Conventional commit format** support

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 📖 Usage

1. Select a project template (Node.js, Python, React, Docker)
2. Fill in project details (name, description, author)
3. Toggle badges you want to include
4. Add features, tech stack, prerequisites
5. Add install commands and env vars
6. Preview the generated README
7. Copy or download the markdown

## 📋 Sections Included

- Badges (license, version, build, downloads, stars)
- Project description with screenshot
- Features list
- Tech stack table
- Prerequisites
- Installation commands
- Environment variables
- Usage instructions
- API endpoints table
- Contributing guide
- License
- Acknowledgements
- Author info

## 🛠️ Tech Stack

- React 18

- react-markdown
- Form-based markdown generation
