# Markdown Resume Builder

A web application that lets you write your resume in Markdown, preview it live, and export to PDF.

## Features

- **Split Pane Editor**: Markdown editor on the left, live preview on the right
- **Default Template**: Pre-loaded resume template to get started quickly
- **Print/Export**: One-click PDF export using browser print functionality
- **Theme Switcher**: Toggle between light and dark themes
- **Responsive Design**: Works on desktop and tablet screens
- **Real-time Preview**: See changes instantly as you type

## Installation

```bash
npm install
```

## Usage

```bash
# Development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Open your browser and navigate to the URL shown in the terminal (usually `http://localhost:5173`).

## How to Use

1. Write your resume in Markdown in the left panel
2. See the live preview on the right panel
3. Use the toolbar to switch themes or print/export to PDF
4. Click "Print / PDF" to open the print dialog and save as PDF
